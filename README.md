# 🚘 AutoPrice AI – Car Price Prediction

## 📌 Overview

**AutoPrice AI** is a Machine Learning web application that predicts the estimated price of a car based on its specifications.

The project uses a **Decision Tree Regression** model trained on automobile data. A user can enter vehicle dimensions, engine specifications, and mileage information through an interactive **Streamlit** interface and receive an estimated car price.

The application also allows users to download the prediction result as a CSV report.

---

## 🎯 Objectives

* Predict the estimated price of a car using Machine Learning.
* Analyze important automobile specifications.
* Provide a simple and interactive prediction interface.
* Deploy the trained ML model through Streamlit.
* Allow users to download prediction results.

---

## 🧠 Machine Learning Model

The project uses:

**Algorithm:** Decision Tree Regressor

The model is trained using an 80:20 train-test split with `random_state=42`. Model performance is evaluated using:

* R² Score
* RMSE (Root Mean Squared Error)

The trained model and feature names are saved in `car_price_model.pkl`.

## 🧹 Data Preprocessing

The training script performs the following preprocessing steps:

* Loads the automobile dataset using Pandas.
* Replaces `?` values with missing values.
* Converts cylinder names such as `two`, `three`, `four`, etc. into numerical values.
* Converts selected columns into numeric format.
* Fills missing numerical values using the median.
* Selects relevant input features.
* Separates input features `X` and target variable `y`.

---

## 🌳 Decision Tree Regression

A **Decision Tree Regressor** is trained to learn the relationship between automobile specifications and their prices.

```python
model = DecisionTreeRegressor(random_state=42)
model.fit(X_train, y_train)
```

The trained model is then saved using Pickle for use in the Streamlit application.
